## PCキッティング：機器ごとに残す7工程

以下は一般的なひな形です。お客様の仕様書・承認済み構成・セキュリティ基準に合わせて変更してください。アプリ専用のインポート形式ではなく、項目を検討する汎用CSVです。

|工程|確認すること|記録の例|
|---|---|---|
|作業前|対象機器の照合|管理番号・シリアル番号・担当者|
|初期設定|OS・端末名の確認|承認済み構成との差異|
|更新|更新適用状況|実施日時・再起動後の確認|
|業務アプリ|指定アプリの起動|アプリ名・起動結果|
|接続|指定ネットワークへの接続|接続可否・問題の内容|
|最終確認|例外・保留の確認|作業者・確認者・未解決事項|
|引き渡し|台帳との照合|引き渡し日時・受領確認|

### チェックリストを使い始める手順

1. CSVを開き、仕様に含まれない項目を削除します。
2. 問題なしとする判定条件と、問題がある場合の連絡先を決めます。
3. 架空の管理番号（例：PC-001）や少数のテスト機器で、記入内容を確認します。
4. 保留・未確認・完了を区別し、再確認する担当者を決めます。
5. 複数人で記録する前に、記入例を共有します。

パスワード・秘密鍵・認証コードは記入しないでください。実在する顧客情報、社内資料、端末情報を、この公開リポジトリのIssueやコメントへ投稿しないでください。

## マシュマロチャレンジ：40分で実施する例

頂上にマシュマロを載せた自立式のタワーを、限られた材料と時間で作るチーム活動です。1チーム3〜5人を目安に、会場と人数に合わせて調整します。

### 1チーム分の材料

|材料|数量|
|---|---|
|乾燥パスタ|20本|
|テープ|90cm|
|ひも|90cm|
|マシュマロ|1つ|
|はさみ|1つ|

SONA CRAFTの進行アプリ内の配布物案内に合わせた数量です。全チームで同じ条件にしてください。主催者は机、メジャー、大画面につなぐ端末、予備材料を用意します。食材のアレルギー、衛生面、はさみの扱い方を確認し、工作に使った材料の飲食は避けてください。

### 当日の時間配分

|工程|時間|進行役が確認すること|
|---|---|---|
|説明・チーム分け|7分|目的、ルール、測定方法、材料の配布|
|制作|18分|相談も含めて制限時間内で制作|
|計測・結果発表|5分|手を離して自立した状態で同じ方法で計測|
|振り返り|10分|試したこと、困ったこと、次に変えることを共有|

合計40分は運営例です。人数に応じて調整してください。

### 7つのルール

1. できるだけ高い、自立するタワーを作る。
2. 頂上にマシュマロを載せる。
3. 足場を机に固定しない。
4. パスタ・テープ・ひもの加工は可能。
5. マシュマロは切らない。
6. 計測中も手を離して自立させる。
7. 作戦タイムを含め、制限時間内に作る。

### 振り返りの問い

- 最初の計画と、試して分かったことはどう違いましたか。
- 困ったことを、いつ、どのようにチームへ共有しましたか。
- もう一度挑戦するなら、何を早めに試しますか。

[無料の進行アプリ・18分タイマーを開く](https://marshmallow.sona-craft.com/)

チーム分け、ルール説明、タイマー、高さ計測、結果発表に対応しています。チームや設定はブラウザに保存されます。別のPCへ移す場合は、設定CSVをエクスポート・インポートしてください。
